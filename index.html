Domina el Flujo de Trabajo con **GitHub**

Estandariza, colabora y fusiona tus proyectos sin conflictos con nuestro proceso de 9 pasos.

Nuestro Flujo de Trabajo

1
🍴

Fork del Repositorio

Cada compañero crea su propia copia del repositorio principal en su cuenta de GitHub.

→
2
💾

Clonar Localmente

Descargamos el código en nuestra máquina local para comenzar a trabajar.

→
3
🌿

Crear una Rama

Creamos una rama para cada característica o corrección que trabajamos.

4
📝

Hacer Commits

Guardamos nuestros cambios con mensajes claros y descriptivos.

→
5
⬆️

Push a GitHub

Subimos nuestros cambios a nuestro fork en GitHub.

→
6
🔀

Pull Request

Solicitamos que nuestros cambios se fusionen con el repositorio principal.

7
👀

Revisión por Pares

Los compañeros revisan y comentan sobre los cambios propuestos.

→
8
✅

Fusionar (Merge)

Los cambios aprobados se fusionan al repositorio principal.

→
9
🔄

Actualizar Local

Actualizamos nuestro repositorio local con los cambios del equipo.

Herramientas y Comandos

🔧

Git

Sistema de control de versiones distribuido que usamos para trackear cambios.

git --version
